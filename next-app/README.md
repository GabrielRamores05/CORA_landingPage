# CORA Next.js Scaffold

This folder is a safe, minimal Next.js scaffold for migrating the existing landing page.

Quick dev:

```bash
npm install
npm run dev
```

Notes:
- Integrations (EmailJS, Meta Pixel, HubSpot) are preserved in `src/pages/_document.tsx`.
- Move `images/` from the root into `next-app/public/images/` when you're ready.
